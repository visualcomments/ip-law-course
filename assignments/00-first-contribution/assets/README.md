# Изображения записей (assets)

Сюда кладут **файлы картинок** для мультимодальных записей
(`figures[]` в схеме датасета). Путь в записи указывается относительно корня
репозитория, например `assignments/00-first-contribution/assets/<файл>.png`.

Правила (подробно — в `../README.md`):

- `rights: "own"` — график/диаграмма **перерисованы вами** из чисел источника;
- `rights: "PD" | "CC0" | "CC-BY-4.0" | "CC-BY-SA-4.0" | "official-document"` — свободные;
- `rights: "permission"` — есть письменное разрешение (приложите в PR);
- **сырые** изображения из проприетарных источников сюда класть нельзя — они не публикуются.

Запись попадает в датасет на HuggingFace, только если права всех её изображений
публикуемы **и файлы существуют** в репозитории. Сборщик (`../dataset-schema/publish.py`)
копирует изображения в датасет вместе с записями.
