# Сдача результатов (submissions)

Положите сюда файл **`records-<ник>.jsonl`** — результат базового задания эксперта
(3 записи по схеме, прошедшие проверку):

```bash
python3 ../dataset-schema/validate.py records-<ник>.jsonl   # должно быть errors=0
```

Имя файла — ваш ник латиницей (например, `records-ivanov.jsonl`). Один участник —
один файл (дописывайте свои записи в тот же файл).

`record_id` должен быть уникальным среди всех submissions. Повтор внутри файла
или между файлами останавливает сборку, даже если записи одинаковые. В сообщении
об ошибке указаны идентификатор, оба файла и номера строк.

После попадания файла в ветку `main` (напрямую или через PR) workflow
`submit-dataset` проверяет все submissions, объединяет их, отбирает записи с
публикуемой лицензией и обновляет датасет на HuggingFace. Записи с `cite-only`/
`unknown` остаются в репозитории, но в открытый датасет не публикуются.
