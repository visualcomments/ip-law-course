# Первое задание: вклад в датасет курса (базовое)

Это **первое задание курса** и одновременно ваш первый вклад в открытый проект.
Курс «Право интеллектуальной собственности» — это и репозиторий-проект: полезная
работа остаётся в нём для следующей группы и попадает в открытый датасет на
HuggingFace. Роль выбирается участником; задание одно на занятие.

Курс-специфичная цель: собрать данные об **изменениях в статьи НПА** (нормы
ГК РФ ч. IV и др.) — какой закон, какую статью и как изменил.

## Роли

| Роль | Что делает | Что остаётся в проекте |
|---|---|---|
| **Эксперт** (работа с данными) | извлекает и размечает записи по схеме проекта | записи датасета, проверенные цитаты |
| **Разработчик** (инфраструктура) | код, тесты, CI, воспроизводимый запуск | принятый PR, зелёный CI |

Роли можно совмещать.

## Роль «Эксперт» — базовое задание (3 записи)

1. Возьмите материал занятия: `make session n=03`, `make assignment n=03`
   (или любой темы по вашему треку). Источники — см. `istochniki.md`.
2. Соберите **3 записи** профиля `amendment` по схеме
   `dataset-schema/universal-record.schema.json`.

**Проще всего — через агента (opencode).** Запустите opencode и введите
`/expert-ip-law` — агент «Эксперт-право» сам проведёт вас по 2–3 вопросам,
возьмёт **дословную** цитату из источника, заполнит схему и проверит результат
(в этом случае за вас работает `dataset-schema/expert_record.py`).

**Вручную** — по одному из способов:
```bash
# 1) найти фрагмент-якорь
python3 dataset-schema/expert_record.py find --file "reading_ru/<файл>.txt" --phrase "147-ФЗ"
# 2) собрать запись (цитата берётся дословно из файла)
python3 dataset-schema/expert_record.py add --kind amendment --nick <ник> \
  --out records-<ник>.jsonl --file "reading_ru/<файл>.txt" --phrase "147-ФЗ" \
  --source-law "ГК РФ" --article "ст.1252" \
  --amending-doc "Федеральный закон от 01.07.2017 № 147-ФЗ" --predicate изменена \
  --ts 2017 --change "Закон изменил статью 1252 ГК РФ."
# 3) проверить
python3 dataset-schema/validate.py records-<ник>.jsonl
```

3. Положите результат в **`submissions/records-<ник>.jsonl`** (имя файла — ваш ник
   латиницей) и отправьте в проект (PR или, если разрешено, коммит в `main`).
   После слияния данные автоматически попадут в датасет на HuggingFace
   (workflow `submit-dataset`).

**Критерий приёмки:** `validate.py` → `errors=0` (структура верна); у каждой записи
есть источник и координата; `evidence_quote` — дословная подстрока источника;
`predicate` — из списка схемы. Все записи помечаются `review.status="proposed"`
(содержательно проверяет преподаватель).

**Оценка:** 1 выполненное задание — 8/10, 2 — 9/10, 3 и более — 10/10
(доп. задания — из пула занятия).

## Лицензирование (важно)

Схема поддерживает два режима работы с источником:

- **дословная цитата** (`provenance.derivation="verbatim_quote"`, по умолчанию) — только из
  корпуса/свободных источников; `evidence_quote` обязателен;
- **факты своими словами** (`source.license="facts-derived"`, `provenance.derivation="facts_reworked"`) —
  для **проприетарных** источников: дословный текст не копируется, берутся только факты
  (статья закона, номер, дата, содержание изменения), изложенные своими словами; сообщения о
  событиях и фактах не охраняются авторским правом (ст. 1259 п. 5 ГК РФ). Для таких записей
  `evidence_quote` — пусто, `source.coord` — обязательно.

Также можно добавлять изображения (`figures[]`): публикуются только «свои» (перерисованные),
свободные или разрешённые; сырые картинки из проприетарных источников — нельзя.

В открытый датасет попадают записи, у которых `source.license` — публикуемая:
`PD`, `CC0`, `CC-BY-4.0`, `CC-BY-SA-4.0`, `official-document`, `facts-derived`. Записи с
`cite-only`/`unknown` и записи с непубликуемыми правами на изображения **в датасет не
публикуются** (остаются в репозитории как учебный материал). Это проверяет
`dataset-schema/publish.py`.
