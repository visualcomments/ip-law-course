# «Право интеллектуальной собственности» — открытый аспирантский курс

Открытый репозиторий курса **«Право интеллектуальной собственности»**
(осенний семестр, **16 занятий**), полностью раскрывающих темы: авторское
право (история, объекты, субъекты, содержание, ограничения, сроки,
передача, смежные права, защита, цифровая эпоха), патентное право
(история, объекты, заявка, экспертиза, права, защита, биотехнологии),
средства индивидуализации (товарные знаки), международная система ИС.

## Что внутри

- **16 занятий** `lectures/NN_*.md` — тезис, разбор с правовыми
  конструкциями, верифицируемые цитаты, «Вопросы для самопроверки»,
  «Задания» (в т.ч. итоговое эссе).
- **Верифицированный корпус** `CORPUS.md` / `PROVENANCE.md`:
  - официальные тексты (международные договоры — Бернская конвенция,
    TRIPS; не являются объектами авторского права);
  - статьи **Wikipedia (CC BY-SA 4.0)** по праву ИС (RU + EN);
  - книги в **общественном достоянии** (Putnam, Birrell по истории
    авторского права).
- **RAG-индекс** (Annoy + fastembed) на Google Диске; `tools/index_fetch.py`
  скачивает архив, сверяет SHA-256 и разворачивает локально
  (`make index-fetch`).
- **Автоматическая верификация цитат** `make verify` → `verification/REPORT.md`
  (0 ошибок после правок).
- **Агент-готовность**: `AGENTS.md` (co-learner botai), `syllabus.json`,
  `Makefile`, инструменты (`rag_search`, `session_material`,
  `assignment_brief`, `rag_api`, `quote_finder`), навыки-зеркала
  `.agents/.claude/.cursor`.
- Без упоминаний вуза и локальной инфраструктуры.

| Путь | Содержание |
|---|---|
| `syllabus.md`, `syllabus.json` | Программа курса |
| `lectures/` | 16 занятий |
| `citations.md` | Правила цитирования и карта «занятие → источники» |
| `PROVENANCE.md` | Лицензии корпуса |
| `verification/REPORT.md` | Верификация цитат |
| `tools/` | Поиск, index-fetch, верификация, материалы и задания занятия, RAG-API |
| `Makefile` | Короткие цели (`make help`) |

## Быстрый старт

```bash
make help                 # цели
make index-fetch URL="<ссылка на архив на Google Диске>"  # установить индекс
make search QUERY="товарные знаки" -k 5                   # поиск по корпусу
make session n=10                                         # материал занятия
make assignment n=10                                      # вопросы и задания
make verify                                               # проверить цитаты
```
