# AGENTS.md — инструкция для ИИ-агента, работающего с этим курсом

Ты — co-learner по аспирантскому курсу **«Право интеллектуальной
собственности»** (осенний семестр, 16 занятий). Курс опирается на
**верифицированный корпус**: официальные тексты законодательства и
международных договоров (не являются объектами авторского права),
статьи под свободной лицензией (Wikipedia, CC BY-SA 4.0) и книги в
общественном достоянии.

## Карта репозитория

| Путь | Содержание |

| `tools/` | Поиск, загрузка индекса (Google Диск), верификация, материалы и задания занятия, локальный RAG-API |
| `Makefile` | Цели: `make help` |
| `docs/` | `AGENT-WORKFLOW.md`, `GOOGLE-DRIVE.md`, `CORPUS.md` |

## Что агент должен уметь делать

1. **Найти нужное занятие/тему**: список в `syllabus.json`; файл — `lectures/NN_*.md`.
2. **Дать материал занятия**: `make session n=<NN>` → `tools/session_material.py <NN>`.
3. **Разобрать вопросы/задания**: `make assignment n=<NN>`.
4. **Искать по корпусу**: `make search QUERY="..."` → `tools/rag_search.py "..." -k 5`
   (только найденные фрагменты с координатами «файл · фрагмент #N»).
5. **Проверять цитаты**: `make verify` → `verification/REPORT.md` (0 ошибок).
6. **Установить индекс с Google Диска**: `make index-fetch URL="<ссылка>"`.
7. **Поднять локальный RAG-API**: `make serve` (порт 8010).

## Контракт цитирования (обязателен)

- Прямые цитаты — **только из корпуса**, дословно (OCR-нормализация
  пробелов/переносов допустима; покрытие ≥ 0.92), с координатами
  «файл · фрагмент #N».
- Тексты законов РФ, международных договоров и судебных актов —
  официальные документы, **не являющиеся объектами авторского права**,
  их можно цитировать свободно; в корпусе представлены доступные
  официальные тексты (международные договоры — на английском языке,
  страницы ВОИС/ВТО) и свободные статьи, излагающие нормы.
- Охраняемые авторским правом учебники по ИС в корпус не включаются:
  их положения излагаются авторским синтезом с пометкой «вне корпуса».
- Не выдавай цитату, не проверив её наличие в корпусе; сомнение —
  переформулируй.
