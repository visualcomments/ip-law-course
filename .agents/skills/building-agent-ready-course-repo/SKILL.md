# Skill: building-agent-ready-course-repo

Библиотека **проверенных приёмов** для создания и ведения **открытого
учебного репозитория курса**, рассчитанного на работу ИИ-агента
(co-learner / harness типа botai), с **верифицированным корпусом
свободных источников**, RAG-индексом на Google Диске и безопасной
публикацией. Сформирована по итогам **трёх реализованных проектов**:

- «История России: история и философия науки и технологий» (бакалавриат, 30 занятий);
- «История и философия науки» (аспирантура, кандидатский экзамен, 26 занятий);
- «Право интеллектуальной собственности» (аспирантура, осенний семестр, 16 занятий).

## Когда применять

- строишь заново или поддерживаешь репозиторий курса для агента;
- нужно: программа → корпус цитируемых текстов (только свободные лицензии)
  → автоматическая проверка цитат → RAG-индекс → распространение без
  серверов (Google Диск) → очистка от брендов и локальной инфраструктуры.

## Уточнения у заказчика (спросить ДО старта)

Согласовать в начале (иначе переделки): **название репозитория**,
**число занятий и разбивку по семестрам** (по слайдам/РУП или свободно),
**состав корпуса** (только PD / законы+практика / максимум со статьями),
**нужен ли вводный слайд-обзор или сразу содержательная тема № 1**.

## Принципы

1. **Верифицируемость.** Каждая прямая цитата — дословно из корпуса,
   с координатами «файл · фрагмент #N», проверяется скриптом
   (покрытие ≥ 0.92 против letters()-нормализованного текста —
   ё→е, только буквы).
2. **Только свободные лицензии.** Корпус: публичное достояние (PD),
   официальные документы (законы, договоры, судебные акты — не объекты
   авторского права), статьи Wikipedia **CC BY-SA 4.0**, датасеты с
   открытыми лицензиями (GPL-3.0). Каждому файлу — запись в
   `PROVENANCE.md` (документ + лицензия + источник).
   Охраняемые авторы XX–XXI вв. — **никогда не цитируются**,
   излагаются авторским синтезом с пометкой «вне корпуса».
3. **Агент-первым.** Корень — `AGENTS.md` (карта, контракт цитирования,
   команды) + машиночитаемая программа (`syllabus.json`) + файлы
   `track.md`/`progress-*` + навыки-зеркала `.agents/`, `.claude/`,
   `.cursor/`, `tools/` + `Makefile`.
4. **Портативность.** В репозитории нет локальных путей, имён хостов,
   IP, серверных схем. Всё внешнее — через переменные окружения
   (`FALT_CORPUS_ROOT`, `FALT_TXT_DIR`, `FALT_INDEX_DIR`, `FALT_INDEX_URL`,
   `FALT_SERVER` — последняя только для сборки, на локальной машине).
5. **Самодостаточность индекса.** Индекс (Annoy + эмбеддинги + чанки +
   config) упаковывается в архив и распространяется через **Google Диск**:
   манифест с SHA-256 + `tools/index_fetch.py` (скачивание, проверка суммы,
   атомарная установка). Никакого сервера для поиска не нужно.
6. **Тредмарк-безопасность.** Никаких упоминаний вузов/подразделений;
   чистые название, описание репозитория и история (filter-repo при
   необходимости).

## Процедура (чек-лист)

1. **Программа курса.** Если даны слайды (`*.pptx`) — извлечь темы
   через python-pptx (заголовки слайдов), сжать в нужное число занятий,
   записать `syllabus.md` + `syllabus.json` (поля: n, sem, title, module).
2. **Корпус (`FALT_CORPUS_ROOT/txt/`).**
   - PD-книги: Internet Archive `_djvu.txt` (метаданные: `metadata/<id>`,
     файл с суффиксом `_djvu.txt`), en.wikisource raw, вики-зеркала.
   - Официальные тексты: договоры — страницы WIPO/WTO (HTM→txt),
     законы РФ — официальные порталы/ФИПС (HTML-извлечение).
   - Судебная практика: HuggingFace-датасеты
     (`api/datasets/<org>/<name>` → `resolve/main/<файл>?download=true`,
     LFS; pandas; **keyword-фильтр релевантности**; срезать
     instruction-обёртки; отбирать представительное подмножество).
   - Wikipedia RU/EN: `action=raw` (urllib, свой User-Agent), срезать
     разметку/шаблоны/сноски. Сохранять согласованные имена
     (`wiki_ru__X.txt`, `law__X.txt`, `practice__X.txt`, `pd__X.txt`).
3. **Верификация цитат.** Все цитаты в лекциях — из реальных пассажей:
   вставлять их **только как вербатим-отрывки из файлов** (функция
   «параграф по ключевым словам» поверх raw-текста файла), никогда
   «по памяти» — OCR-тексты различаются («f/s», «deftroy», переносы).
   Прогон `tools/verify_quotes.py` до **0 ошибок**; обновлять
   `verification/REPORT.md`; проставить номера «фрагмент #N» по
   `chunks.jsonl` (толерантный паттерн: источник может быть не
   соседней строкой — пустая строка/`>` между цитатой и источником).
4. **Индекс.** Нарезка на чанки → эмбеддинги (fastembed
   `paraphrase-multilingual-MiniLM-L12-v2`) → Annoy (angular).
   Кластер: локальный пул процессов (threads=1 на воркера) + сервер
   по сети (шарды на сервер с таймаутами и локальным фолбэком).
   Чанки: **1400/140** для книг/длинных текстов; разрешено 512/128 для
   коротких источников. При изменении корпуса — **обязательная
   пересборка** индекса и новый архив+манифест. В `config.json` —
   backend `cpu-cluster (local pool + <server> via Ethernet)`.
5. **Google Диск.** Собрать архив `course-index-<курс>-<дата>.zip`,
   посчитать SHA-256 для архива и каждого файла → заполнить
   `index-manifest.json` и `.example.json` (url — пустой, пока пользователь
   не зальёт архив). После получения share-ссылки: вписать url, **протестировать
   полный цикл** `index-fetch` во временный каталог
   (`FALT_CORPUS_ROOT=<temp>`) — проверить «SHA-256 подтверждена» и
   sanity (n_chunks, n_files) — затем коммит манифеста.
6. **docs/лицензии.** `PROVENANCE.md` (лицензии всех файлов корпуса),
   `CORPUS.md` (состав/сборка/индекс), `citations.md` (карта
   «занятие → источники»), `docs/GOOGLE-DRIVE.md`, `docs/AGENT-WORKFLOW.md`.
7. **Публикация.** Перед push: глобальный grep запрещённых терминов
   (вузы, бренды, имена хостов, IP, локальные пути) → 0. Описание
   репозитория на GitHub чистое. При переписывании истории:
   `git bundle`-бэкап → `git filter-repo --replace-text <rules>`
   (правила строго UTF-8!) → `--force` → re-add origin →
   `git push --force origin main`; проверка `git log -S`.
   Переименование репо — `gh api -X PATCH ... -f name=...` + set-url.

## Проверенные подводные камни

- **Блоки цитат в Markdown**: пустая строка/строка `>` между «Цитата» и
  «Источник», вложенные или отсутствующие `« »` ломают парсинг — захват
  становится гигантским или пустым, verify ошибочно сообщает «file/quote
  too short»/низкое покрытие. Норма: одна цитата = один блок с парой
  `> **Цитата:** «...»` + `> **Источник:**` без промежуточных строк.
- **«file/quote too short»** также возникает, когда файл отсутствует в
  кэше (сломана переменная корпуса) — сначала проверь кэш файлов, потом
  длину цитаты.
- **cmd.exe `set VAR=... &&`** добавляет хвостовой пробел к значению:
  писать `set "VAR=<путь>"` (в кавычках).
- **glob на Windows** не матчит смешанные разделители (`C:\x\txt/*.txt`):
  нормализовать `os.path.join(...).replace("\\","/")`.
- **multiprocessing (Windows/spawn)**: функции пула — только на уровне
  модуля (вложенные не пиклятся, `EOFError: Ran out of input`);
  большие списки в аргументах задач опасны — передавать пути к
  файлам-шардам. fastembed: `threads=1` на воркера (иначе
  oversubscription ядер). Вывод с `-u` и `flush=True`.
- **PowerShell**: `Add-Content` пишет ANSI — кириллица ломается; inline
  `python -c` с кириллицей — писать скрипты-файлы; `py_compile` после
  правок; перед перезаписью `annoy.index` убивать python (mmap-лок).
- **Google Диск (большие файлы)**: страница «Virus scan warning»
  (confirm=t, `drive.usercontent.google.com/download` + uuid) — у
  `index_fetch.py` свой flow; тестировать скачиванием в temp до
  полного прогона.
- **OCR**: двойные слоги, колонтитулы, старинная типографика («f/s»,
  «impreffions») — нормализация letters(), порог 0.92; цитата — только
  фактический отрывок файла.
- **Датасеты HF — большой объём**: качать через LFS-ссылку
  (`?download=true`), парсить потоково/чанками, извлекать
  репрезентативную выборку (не весь файл), квотировать лицензию в
  PROVENANCE и размер выборки.
- **Первый Drive-файл от пользователя** может быть не тем архивом:
  сверять sha архива И содержимое; распаковывать только при совпадении.

## Быстрые команды

```bash
make help                       # цели
make index-fetch URL="<ссылка>" # скачать индекс с Google Диска
make search QUERY="..."         # поиск по корпусу
make verify                     # проверка цитат (0 ошибок — норма)
make session n=NN / make assignment n=NN
# верификация с окружением (Windows):
#   set "FALT_CORPUS_ROOT=C:\...\corpus" && python -u tools\verify_quotes.py
# сборка индекса (кластер):
#   set FALT_SERVER=user@10.0.0.2 && python -u scripts\<course>_build_index.py
# история:  git bundle create B --all && git filter-repo --replace-text rules.txt --force
#           git remote add origin <url> && git push --force origin main
```
