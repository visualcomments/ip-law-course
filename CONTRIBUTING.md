# Участие в курсе (CONTRIBUTING)

Курс «Право интеллектуальной собственности» — это открытый проект: репозиторий
**и есть** учебный материал. Полезная работа участников остаётся в проекте для
следующей группы и попадает в открытые датасеты на HuggingFace.

> Этот файл — авторитетное руководство по участию. Агент-соученик (botai) читает
> его и **предлагает описанное здесь первое задание** в начале работы
> (см. `botai/course.json`, `contribution.enabled=true`).

## С чего начать: первое задание (роль «эксперт»)

**`assignments/00-first-contribution/`** — базовое задание, с которого начинают
все: собрать **3 записи** о **изменениях в статьи НПА** (ГК РФ ч. IV и др.) по
схеме проекта. Полный текст, роли (эксперт/разработчик), критерий приёмки и
оценка — в `assignments/00-first-contribution/README.md`.

Коротко:
- проще всего — через агента opencode: команда `/expert-ip-law`;
- либо вручную помощником `dataset-schema/expert_record.py` (берёт дословную цитату);
- результат — `assignments/00-first-contribution/submissions/records-<ник>.jsonl`;
- проверка — `dataset-schema/validate.py` (`errors=0`).

Сдача: откройте pull request (или, если у вас есть право записи, коммит в `main`).
После попадания в `main` workflow `submit-dataset` проверяет submissions,
объединяет их и обновляет датасет на HuggingFace.

## Роли

| Роль | Вклад | Остаётся в проекте |
|---|---|---|
| **Эксперт** | разметка данных: записи датасета, проверка цитат и связей, задачи для оценки | записи датасета, проверенные цитаты |
| **Разработчик** | код, тесты, CI, воспроизводимый запуск, инструменты | принятый PR, зелёный CI |
| **Исследователь** *(опц.)* | метод, постановка задачи соревнования | описанный метод |

## Как внести изменение

1. Определитесь с ролью и возьмите задачу из `assignments/00-first-contribution/`.
2. Ветка от `main` → изменение → проверка → pull request.
3. В описании PR: что и зачем, кому это помогает, как проверить, источники и
   **где использовался ИИ**.

Правила репозитория:
- изменения в `main` — по возможности через PR; история не переписывается,
  force-push запрещён;
- `make verify` — цитаты только из корпуса, дословно, с координатами
  «файл · фрагмент #N» (покрытие ≥ 0.92); охраняемые тексты — только авторский
  синтез с пометкой;
- не коммитить секреты, персональные данные, файлы без ясной лицензии.

## Лицензии

- код — GPL-3.0-or-later; материалы — CC-BY-SA-4.0 (см. `LICENSE`, `PROVENANCE.md`).
- в открытый датасет публикуются только записи с публикуемой лицензией источника
  (PD / CC0 / CC-BY-4.0 / CC-BY-SA-4.0 / official-document); `cite-only`/`unknown`
  остаются в репозитории как учебный материал и не публикуются.

## Раскрытие ИИ

ИИ-содействие допустимо и раскрывается (`provenance.tool`, `contribution.ai_disclosure_required`).
Участник понимает и защищает свой вклад; агент не коммитит и не публикует за него.
