# Программа курса «Право интеллектуальной собственности» (осенний семестр)

Аспирантский курс, **один семестр (осень)** — 16 занятий. Программа
построена на основе учебных материалов курса (19 презентаций) и охватывает
авторское право, патентное право и средства индивидуализации, а также
международную систему интеллектуальной собственности (ИС) и судебную
практику.

Курс опирается на **верифицированный корпус**: официальные тексты
законодательства (Гражданский кодекс РФ, часть IV), международные
договоры (Бернская и Парижская конвенции, TRIPS, Договор ВОИС по
авторскому праву), судебную практику, статьи под свободной лицензией
(Wikipedia, CC BY-SA) и книги в общественном достоянии. Законы и судебные
акты не являются объектами авторского права — их тексты можно приводить и
цитировать без ограничений (ст. 1259 ГК РФ).

## Принципы курса

- Каждое занятие раскрывает тему **полно**: тезис, правовые конструкции,
  нормы, практика, дискуссия.
- Прямые цитаты — только из корпуса (официальные тексты, свободные статьи,
  книги PD), с координатами «файл · фрагмент #N».
- Произведения авторов XX–XXI вв. (в т.ч. учебники по ИС) в корпус не
  включаются: их положения излагаются авторским синтезом («вне корпуса»).
- Форма контроля: итоговое эссе/реферат по избранной теме ИС с ссылками
  на корпус.

## Как работать с курсом

Каждое занятие — отдельный файл в [`lectures/`](lectures/) со своей
структурой: тезис, источники и свидетельства из корпуса, авторский синтез,
вопросы для самопроверки и задания.

| Шаг | Команда | Что даёт |
|---|---|---|
| Материал занятия | `make session n=05` | Полный текст занятия с заданиями |
| Вопросы и задания | `make assignment n=05` | Только вопросы и задания |
| Поиск по корпусу | `make search QUERY="срок охраны"` | Фрагменты с координатами «файл · фрагмент #N» |
| Проверка цитат | `make verify` | Сверка каждой цитаты с корпусом |
| Состояние курса | `make status` | Готовность занятий и корпуса |
| Инструменты | `make help` | Все доступные цели |

Полный разбор рабочего процесса — [`docs/AGENT-WORKFLOW.md`](docs/AGENT-WORKFLOW.md).
