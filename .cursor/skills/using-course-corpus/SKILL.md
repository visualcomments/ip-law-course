# Skill: using-course-corpus

Работа с верифицированным корпусом источников курса «История и философия
науки и технологий» ( , РУП 2025).

## Когда применять

- когда нужно найти материал/цитату по любому сюжету курса (занятия 1–30);
- перед тем как дать обучающемуся объяснение, цитату или проверку задания;
- для подготовки эссе/реферата с обязательными ссылками на корпус.

## Процедура

1. **Локализуй корпус.** `python tools/status.py` покажет путь корпуса
   (`FALT_CORPUS_ROOT`), число файлов, наличие RAG-индекса.
   Если корпуса нет — работай по `citations.md` и `verification/REPORT.md`,
   не выдумывая координаты цитат.
2. **Поиск.** `make search QUERY="..."` или
   `python tools/rag_search.py "..." -k 5 --json`. Ответ — фрагменты с
   координатами `file` + `chunk_id` (текст чанков в `index/chunks.jsonl`).
3. **Цитируй только так:**
   - дословный текст из фрагмента (OCR-нормализация: пробелы/переносы/ё-е;
     двойные слоги OCR допускается очищать);
   - источник: `txt/<файл>` · фрагмент #N;
   - покрытие цитаты в источнике ≥ 0.92 (проверяет `tools/verify_quotes.py`).
4. **Авторский синтез.** Если факт нельзя подкрепить цитатой корпуса —
   формулируй своими словами и помечай «вне корпуса»; не называй это цитатой.
5. **Проверка.** После правок с цитатами запусти `make verify` — отчёт
   `verification/REPORT.md`; расхождений быть не должно.

## Материалы занятия

- `make session n=<NN>` — `tools/session_material.py NN` (занятие + цитаты +
  источники);
- `make assignment n=<NN>` — `tools/assignment_brief.py NN` (вопросы и задания).

## Ограничения

- В репозитории курса лежат только карта источников и верификация; полные
  тексты корпуса и RAG-индекс — локально (см. `CORPUS.md`).
- Цитаты из современных (не публично-доступных) работ в корпус не включаются;
  профильные темы  (ИИ, БАС, радиолокация) опираются на документы
  public domain (NASA, доклады 2016/2019) — см. `citations.md`.
