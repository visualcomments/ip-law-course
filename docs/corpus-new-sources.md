# Лицензии и провенанс источников корпуса (расширение 2026-09-13)

Реестр источников, добавленных в корпус курса «Право интеллектуальной
собственности» сверх прежнего состава (35 файлов). Правило включения: только
общественное достояние или явная свободная лицензия (CC0 / CC BY / CC BY-SA /
CC BY-NC / CC BY-ND). «Открытый доступ без заявленной лицензии» в корпус не
включался.

## 3. Научные статьи под свободными лицензиями (`oa__*`) — 50 файлов

Открытый доступ, лицензии подтверждены через DOAJ на уровне журнала и
дополнительно через Crossref по DOI. Манифест с лицензией по каждой статье:
`catalog/doaj_law_admitted.json`.

Тематика: авторское право (история, сроки, ограничения и исключения, fair
use, цифровая эпоха, ИИ и авторство), смежные права, патентное право
(патентоспособность, неочевидность, программные и биотех-патенты, принудительные
лицензии, лекарственный доступ), товарные знаки (включая нетрадиционные и
trade dress), ТРИПС и гармонизация, общественное достояние.

Лицензии: CC BY, CC BY-SA, CC BY-NC, CC BY-ND, CC BY-NC-ND, CC BY-NC-SA.
**Внимание:** лицензии с NC/ND ограничивают коммерческое использование и
производные произведения — для учебного корпуса это допустимо, но при
публикации корпуса ограничение должно быть указано.

## Что сознательно НЕ включено

- **DOAJ-записи без подтверждённой лицензии.** У статей DOAJ поле `license`
  пустое (лицензия лежит на записи журнала) — без проверки через журнал или
  Crossref такая статья не берётся.
- **Парижская конвенция, PCT и др. соглашения** — текст недоступен в свободных
  источниках в полном виде (см. раздел 1); не подменялись пересказом.
- **Современные учебники и комментарии** под коммерческими лицензиями.

```bash
python scripts/fetch_treaties_wikisource.py --txt-dir <корпус>/txt
python scripts/fetch_treaty_parts.py --txt-dir <корпус>/txt   # многочастные
python scripts/fetch_doaj_law.py --txt-dir <корпус>/txt --max 50
python scripts/ia_download.py --prefix pd__ --txt-dir <корпус>/txt --identifiers ...
```
