# «Закон-граф»: адаптированный конвейер подготовки датасета и модели
# предиктивного анализа норм российского права

> **Адаптация подхода top-papers-graph на область права.**
> В исходном проекте (`github.com/top-papers/top-papers-graph`) из научных
> публикаций строится темпоральный граф знаний: вершины — научные открытия
> и термины, рёбра — **причинно-следственные связи между открытиями**
> («X *causes* Y; X *leads to* Y»), а модель прогнозирует новые связи.
>
> Здесь та же логика переносится на российское право: вершинами становятся
> **нормы права** (статья/пункт/часть закона), а вместо связей между
> открытиями строятся связи вида **«внесение поправки → изменение нормы
> права»**. Цель модели — **предиктивный анализ норм права**: по темпоральному
> графу норм и внесённых поправок предсказать, **какие нормы вероятно будут
> изменены** в ближайшем окне.

Пакет `law_graph/` — самодостаточный, без тяжёлых внешних зависимостей
(нужны `pydantic` и `numpy`; `torch_geometric` — опционально для backend
`pyg`). Запускается в офлайн-режиме на синтетическом корпусе поправок.

---

## 1. Что меняется относительно top-papers-graph

| Аспект | top-papers-graph (наука) | Этот конвейер (российское право) |
|---|---|---|
| **Узел графа** | научная сущность / термин | **норма права** (`norm_id` = `закон/ст.N[/п.M]`) |
| **Событие** | публикация с утверждением | **поправка** (ФЗ-N от даты) |
| **Предикат (связь)** | `causes`, `induces`, `leads_to`, `drives`, ... | `изменена`, `дополнена`, `введена`, `изложена_в_новой_редакции`, `признана_утратившей_силу`, `исключена`, `уточнена` |
| **Связь норм** | «открытие зависит от открытия» | `отсылает_к`, `влечёт_изменение`, `требует_приведения_в_соответствие` |
| **Время** | год/дата публикации | **дата вступления поправки в силу** |
| **Задача модели** | предсказать новые связи в графе | **предсказать изменение нормы** (бинарная метка) |
| **Признаки** | рекуррентность термина, соседи, память узла | давность последней поправки, частота поправок за 5 лет, связанность с другими нормами, интенсивность поправок в законе |

## 2. Структура пакета `law_graph/`

```
law_graph/
  schemas.py               # модель данных: LegalNorm, AmendmentEvent,
                           #   LegalTriplet, LegalTaskInstance, norm_id
  corpus_loader.py         # чтение корпуса курса (txt/*.txt) и «норм-чанков»;
                           #   синтетический корпус поправок для офлайн-демо
  amendment_extractor.py   # ИЗВЛЕЧЕНИЕ связей «поправка → изменение нормы»:
                           #   rule_based + LLM-промпт (адаптация temporal_triplet_extractor)
  graph_builder.py         # темпоральный «закон-граф», хронологическое
                           #   разбиение, учебные экземпляры (LegalTaskInstance)
  link_prediction.py       # адаптация tgn_link_prediction: ранжирование норм,
                           #   которые вероятно будут изменены (heuristic + pyg)
  model.py                 # обучаемая логистическая модель на признаках норм,
                           #   метрики (AUC-ROC, precision@k)
  run_dataset.py           # CLI: корпус → граф → датасет → модель → прогноз → отчёт
```

## 3. Модель данных (адаптация `schemas.py`)

**Вершина — норма права.** Идентифицируется стабильно:

```
norm_id("ГК РФ", "ст.1229")        ->  "гк-рф/ст.1229"
norm_id("ГК РФ", "ст.1229", "п.1") ->  "гк-рф/ст.1229/п.1"
```

**Событие — поправка, меняющая норму.** Прямой аналог `TemporalEvent`:

```
AmendmentEvent(
    subject    = "гк-рф/ст.1286",       # что меняется (норма)
    predicate  = "дополнена",           # тип изменения нормы
    object     = "ГК РФ (поправка: ФЗ-35 от 12.03.2014)",
    ts_start   = "2014",                # дата вступления поправки в силу
    evidence_quote = "Открытая лицензия ...",
)
```

**Учебный экземпляр — задача предиктивного анализа нормы:**

```
LegalTaskInstance(
    norm_id, source_law, article, clause, norm_text,
    years_since_last_change,   # давность последней поправки
    amendments_last_5y,        # частота поправок за 5 лет
    referenced_by_active,      # сколько норм на неё ссылаются
    outdegree_norm_links,      # её ссылок на другие нормы
    law_amendment_intensity,   # интенсивность поправок в законе
    label,                     # 1 = норма фактически изменена в окне (T, T']
)
```

## 4. Конвейер (адаптация `pipeline` + `tgNN/event_dataset`)

### 4.1 Извлечение причинно-следственных связей поправок

`amendment_extractor.py` — адаптация `temporal_triplet_extractor`:

- **rule_based**: регулярные выражения по глаголам законодательной динамики
  («Статья 1229 изложена в новой редакции», «Статья 1270 дополнена»,
  «Признать утратившей силу статью 1240»). Сила сигнала задаётся явно
  (аналог `_predicate_strength`);
- **llm**: системный промпт, где научные причинно-следственные связи заменены
  на связи «внесение поправки → изменение нормы» с каноническим списком
  предикатов (см. `SYSTEM_PROMPT`).

### 4.2 Темпоральный «закон-граф» и разбиение

`graph_builder.build_event_stream` + `chronological_split` — та же схема, что в
`tgnn/event_dataset`, но **без утечки будущего**:

- **хронологическое разбиение** применяется только к фактическим событиям
  изменения норм (с датой);
- **структурные связи влияния норм** (`отсылает_к` и т.п.) действуют всегда:
  они переносятся в обучающий граф как контекст и не участвуют в разбиении по
  времени;
- признаки каждой нормы считаются **только по событиям до `train_until`**;
- метка `label=1` ставится, если норма **фактически изменена** в окне
  `(train_until, train_until+W]`.

### 4.3 Модель

Две взаимодополняющие модели (адаптация `tgnn/tgn_link_prediction` +
добавленная обучаемая модель):

1. **`link_prediction.LegalChangeHeuristic`** — интерпретируемый скоринг без
   обучения (рекуррентность поправок, влиятельность нормы, давность,
   интенсивность закона). Есть опциональный PyG TGN-memory backend;
2. **`model.fit_model`** — обучаемая логистическая регрессия на признаках
   нормы, дающая вероятность `p(норма изменится)`. Метрики: AUC-ROC,
   precision@k, accuracy.

## 5. Как запустить

### 5.1 Офлайн-демо на синтетическом корпусе (без внешних данных)

```bash
# из корня репозитория ip-law-course
python -m law_graph.run_dataset --mode synthetic --out runs/law_demo --export
```

Создаёт в `runs/law_demo/`:
- `dataset.jsonl` — подготовленный датасет (признаки + метки);
- `graph.json` — темпоральный «закон-граф»;
- `report.json` — отчёт с топ-прогнозом «какие нормы вероятно будут изменены».

### 5.2 На реальном корпусе курса

```bash
export COURSE_CORPUS_ROOT=/path/to/ip_law_corpus   # каталог с txt/*.txt
python -m law_graph.run_dataset --mode corpus --out runs/law_corpus --export
```

Корпус лежит в `COURSE_CORPUS_ROOT/txt/` (см. `CORPUS.md`). Файлы законов РФ
(например `txt/gk_rf_part4.txt`) проходят норм-чанкинг и rule-based извлечение
поправок; судебная практика и Wikipedia подключаются как контекст норм.

## 6. Интерпретация результата

- **Топ-список норм** (этап 5) — это ответ на вопрос «какие нормы вероятно
  будут изменены». Нормы, помеченные `[ИЗМЕНИТСЯ]`, в обучающих данных
  действительно изменились в окне прогноза (используется для аудита качества,
  а не как будущее знание).
- **Вес признака** (`w`) в обучаемой модели показывает, что сильнее двигает
  вероятность изменения: отрицательный вес у `amendments_last_5y` + высокий у
  `years_since_last_change` интерпретируются как «нормы, давно не менявшиеся,
  при активном законе — «созрели» к изменению».
- **Интерпретируемый скоринг** даёт объяснимый ранг без обучения — удобно для
  курсового разбора и human-in-the-loop проверки экспертом.

## 7. Дальнейшие развития (дорожная карта для курса)

- Подключить **более полный корпус редакций** ГК РФ ч. IV и ФЗ «Об
  авторском праве и смежных правах» (история редакций → даты поправок).
- Использовать **LLM-бэкенд** извлечения поправок (`amendment_extractor.llm`)
  на реальных новеллах и заключениях СИП.
- Добавить **проекцию на статью вендинга норм** (норма как текст) через
  эмбеддинги корпуса (fastembed/Annoy — уже есть в курсе) как дополнительный
  признак семантической близости норм.
- Реализовать `pyg`-бэкенд прогноза (TGN) при установке `torch_geometric`.
