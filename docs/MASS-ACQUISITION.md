# Массовый сбор НПА (курс «Право интеллектуальной собственности»)

Модуль массового сбора официальных текстов нормативно-правовых актов РФ и
карточек законопроектов через официальные API. Легальность и воспроизводимость —
приоритет; персональные данные слушателей не собираются никогда.

## Правовое основание

Согласно **п. 6 ст. 1259 ГК РФ** официальные документы государственных органов
(законы, судебные решения, иные акты) **не являются объектами авторского
права**. Их сбор и включение в датасет и корпус курса допустимы.

## Источники (адаптеры)

| Модуль | Источник | Что даёт |
|---|---|---|
| `law_graph/acquire/pravo.py` | Официальный портал правовой информации (pravo.gov.ru) | Карточки и прямые ссылки на официальные тексты актов |
| `law_graph/acquire/sozd.py` | API СОЗД Государственной Думы | Карточки законопроектов, пояснительные записки |

## Использование

```bash
# Каталог правовых тем/блоков (авторское, смежные, патент, товарные знаки)
python tools/acquire_npa.py topics

# Собрать манифест кандидатов из списка актов (JSON-массив карточек)
python tools/acquire_npa.py manifest \
    --acts-json acts.json \
    --out .local/legal-bronze/candidates.jsonl

# Загрузить тела актов ЛОКАЛЬНО (вне git)
python tools/acquire_npa.py fetch \
    --manifest .local/legal-bronze/candidates.jsonl \
    --out-dir .local/legal-bronze
```

## Право-гейт и безопасность

- Только официальные документы (`official-document`, п. 6 ст. 1259 ГК РФ);
- Только `https` и только хосты из allow-list (pravo.gov.ru, sozd.duma.gov.ru,
  publications.pravo.gov.ru, docs.cntd.ru);
- Байты кладутся **локально** (`.local/legal-bronze/`, вне git);
- **Персональные данные слушателей не собираются и не хранятся**;
- CI-workflow дополнительно сканирует артефакты на email/telegram-упоминания и
  токены, блокируя публикацию при обнаружении.

## Интеграция с юридическим харнессом

После сбора манифеста агент с `legal-agent-harness` в пакетном режиме обходит
его, извлекает связи «поправка → изменение нормы», формирует темпоральный
«Закон-граф» и обучающие примеры (`LegalTaskInstance`), проверяя выход по
`universal-record.schema.json` (профиль `amendmentRecord`).
